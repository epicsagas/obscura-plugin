# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |

## Reporting a Vulnerability

**Do not report security vulnerabilities through public GitHub issues.**

Please use [GitHub Private Vulnerability Reporting](https://github.com/epicsagas/obscura-plugin/security/advisories/new) instead.

### Response Times

| Stage | Target |
|-------|--------|
| Acknowledgement | Within 48 hours |
| Initial assessment | Within 5 business days |
| Patch / fix | Within 90 days |

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Potential impact
- Suggested fix (if available)

### Disclosure Policy

We follow coordinated disclosure — we will work with you to fix the issue before any public announcement. Credit will be given to reporters unless they request anonymity.
